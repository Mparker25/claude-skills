## CAPA Process

### 1. Identification
- Sources: complaints, audits, nonconformances, risk management

### 2. Evaluation
- Determine if investigation needed
- Assign priority and owner

### 3. Investigation
- Gather facts and data
- Root cause analysis (5 Whys, Fishbone, Fault Tree)
- Document findings

### 4. Action Planning
- Immediate containment
- Corrective action (address root cause)
- Preventive action (prevent occurrence)

### 5. Implementation
- Execute action plan
- Verify implementation

### 6. Effectiveness Check
- Define success criteria
- Verify effectiveness (30-90 days typical)
- Close CAPA or escalate

## Common Quality Pitfalls

1. **Documentation overload** - Start lean, scale up
2. **Poor CAPA analysis** - Symptoms vs root cause
3. **Ineffective training** - Document understanding matters
4. **Delayed CAPA closure** - Leads to audit findings
5. **No document control** - Uncontrolled documents in use
6. **Ignoring security** - Critical for connected devices
